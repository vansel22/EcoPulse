# EcoPulse 🌱

**Build More, Waste Less** — a simple school tech fest project.

## What it does
- Records electricity usage (kWh), water usage (litres), and food waste (kg)
- Saves totals in your browser with `localStorage`
- Includes a three-question EcoCity mini game
- Explains SDG 12, SDG 6, SDG 7, and SDG 13

## Run
Open `index.html` in a browser. No installation needed.

## Files
- `index.html` — page content
- `style.css` — green design
- `script.js` — tracking and game logic

## GitHub Pages
Upload the files to a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.

## Note
Numbers are entered by the user; the app does not measure real resource savings. Game points are educational, not verified environmental impact.
